# 上线前合规与隐私检查清单

## 数据来源

- [ ] 已向 GovHK/入境事务处说明商业模式并确认允许的数据使用方式。
- [ ] 只使用获准的公开数据，不访问预约内部流程。
- [ ] 获取频率有明确上限、超时、抖动和指数退避。
- [ ] 页面和邮件清楚标注数据来源及非官方身份。

## 顾客资料

- [ ] 只收集提供服务所必需的邮箱和筛选条件。
- [ ] 不收集 HKID、证件号码、出生日期、签证编号或查询代码。
- [ ] 已发布隐私声明并说明保存期限和删除方式。
- [ ] 日志、备份和错误报告会遮盖邮箱及密钥。

## 通知

- [ ] 每位顾客独立发送，不使用共享 To/CC/BCC 群发。
- [ ] 邮件提供发送者身份、联络方式和退订入口。
- [ ] 退订后立即停止创建新通知。
- [ ] 标题不误导，正文不承诺预约成功。

## 运营

- [ ] 已准备服务条款、免责声明和退款规则。
- [ ] 已验证数据库备份能够恢复。
- [ ] 已设置获取失败、投递失败和服务停止告警。
- [ ] 已完成方案列出的关键自动测试。
- [ ] 未在 Git、聊天记录或数据库中保存 SMTP/API 密钥。
